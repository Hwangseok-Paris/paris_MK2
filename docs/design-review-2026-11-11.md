# 전체 디자인 재검토 — 2026-11-11

범위 정정: 사용자는 홈이 이미 확정됐으며 재검토 대상은 About·Contact라고 명확히 정정했다. 아래 홈·Projects 재설계 제안은 에이전트의 범위 오해로 생성됐으므로 철회한다. 참고 기록만 보존한다. 최신 검토 대상은 `about-contact-focused.html`의 About·Contact 두 안이며 확정 홈·Projects는 유지한다.

상태: 사용자가 디자인 에이전트 분석과 새 시안을 요청했다. 아래 두 안은 검토 제안이며 서비스 적용 승인이 아니다. 기존 구현과 시안 원본은 보존했다.

## 진단

디자인 에이전트가 `src/app/folio.css`, `ProjectCard.tsx`, 홈·Projects·About·Contact 시안과 실제 캡처를 검토했다. 1차 분석 후 새 시안 HTML 및 데스크톱 캡처를 다시 검토했다.

- 홈 1440px 캡처는 대표 작업 3건에 약 2011px 높이를 사용한다. 큰 영문 제목 다음에 담당 역할과 요약을 찾아 읽어야 한다.
- 홈과 목록, About까지 큰 표제·수평선·같은 두 열 행을 반복한다. 페이지별 목적과 작업 간 차이가 시각적으로 약하다.
- About의 ‘해온 일’ 4개는 Projects 내용을 재분류한 반복이다. 새 시안에서는 제거했다.
- 주요 행동과 보조 문구가 비슷한 강도로 표시된다. 선택 상태와 상세 진입을 더 명확히 구분할 필요가 있다.

## 시안

### 비대칭 쇼케이스 — 우선 검토안

- 대표 3건의 역할과 승인 요약을 동시에 표시한다. CIA의 넓은 면과 오스템·NH의 세로 배치로 정보 밀도와 읽는 방향을 바꾼다.
- 어두운 CIA 면·확인된 오스템 주황·중성 NH 면을 사용한다. 공통 버튼/링크는 코발트 계열이며 새 고객사 로고나 제품 UI를 만들지 않는다.
- CIA 제목을 데스크톱 최대128px/모바일88px로 제한했다. 역할·요약을 제목 뒤에 붙이고 상세 버튼만 하단에 둔다. 역할보다 거대한 글자와 공백이 앞서지 않도록 재검토했다.
- Projects는 데스크톱 두 열의 비교 목록, 모바일은 한 열로 정리한다. 한국어 원제와 CIA 풀네임을 유지한다.

### 프로젝트 내비게이터 — 탐색 대안

- 데스크톱 좌측 내비게이션과 대표 작업 선택 목록, 선택 작업의 역할·요약을 병렬로 둔다. 모바일은 상단 내비게이션과 3개 선택 버튼 아래 본문으로 전환한다.
- 선택은 포트폴리오 안의 미리보기만 바꾸고 ‘상세 보기’에서 상세 패널을 연다. 고객사 업무 화면을 모사한 UI가 아니다.
- 장점은 현재 선택과 이동이 분명하다는 점이다. 다른 두 요약을 읽으려면 선택해야 하므로, 모든 요약이 기본 노출되는 기존 안/A와 달라지는 제안이다. 이 변경은 아직 승인되지 않았다.

## 공통 범위

- 두 안에서 홈·Projects·상세·About·Contact를 탐색할 수 있다. 기존 13개 프로젝트와 7개 필터 판정을 사용한다.
- About은 승인 자기소개와 기술 6분류만 둔다. 반복 프로젝트 소개, 본문의 큰 Paris., 이유 없는 소개 문단 글자 차이, 거절된 분류명과 Contact 문구를 넣지 않았다.
- Git·GitLab·SVN, GCP·AWS·Docker 및 확정 이메일을 유지한다. CIA 상세의 사용 기술에는 사용자 확인에 따라 GCP를 추가했다. 서비스 데이터는 변경하지 않았다.
- 프로젝트 내용은 승인된 공개 텍스트다. 공개 제한이 있는 실제 화면, 실데이터, 내부 소스나 실제 고객사 제품처럼 보이는 가상 화면은 넣지 않았다.
- 기존 상세 패널의 시안이며 별도 상세 라우트/서비스 UI를 추가하지 않는다. 대화형 시안은 자연 높이로 내용을 확인하고, 실제 뷰포트 내부 스크롤·URL history는 서비스 구현 검증 항목이다. 외부 링크는 연결 대상만 표시한다.

- Chromium: 두 안 × 4페이지 × 320/390/768/1024/1440px, 총 40개 조합에서 가로 넘침·JS 오류 없음.
- 필터 결과 13/5/6/7/6/2/3, 프로젝트 13건 각각 상세 열기·Escape 닫기·트리거 포커스 복귀 확인.
- 키보드 대표 작업 선택, 밝기 전환·모션 감소, 이메일 대상, About의 반복 콘텐츠 부재·동일 문단 스타일 확인.
- HTML과 1440/390px·다크 캡처는 대화 폴더 `portfolio-design-reset.html`, `design-reset-review/`에 보관한다. 디자인 에이전트의 데스크톱 검토 외 모바일은 주 에이전트가 확인했다.
- 서비스 코드·의존성·DB·배포 변경 없음. 기존 구현은 새 시안 선택 후 별도 승인 범위에서 변경한다.
