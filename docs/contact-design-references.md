## 두 안의 차이

- **이메일 주소 중심:** 본문 폭을 제한하고 실제 주소를 중심에 둔다. 이메일 보내기와 주소 복사를 나란히 배치하며 하단에 세 외부 링크를 둔다. 디자인 에이전트의 기본 추천안이다.
- **메일 버튼 중심:** 주소와 복사 행동은 왼쪽, 단일 원형 메일 CTA는 오른쪽에 둔다. 작은 화살표 움직임과 색 대비로 주요 행동을 드러낸다. 모바일은 주소·행동·외부 링크 순서로 쌓는다.

## 검증

- 두 안 × 320/390/768/1024/1440px 10조합에서 넘침·JS 오류 없음. 모바일 이메일→행동→링크 순서를 확인했다.
- 실제 이메일 표기·mailto 대상, 키보드 Enter, 다크·모션 감소, 모바일 보기 버튼을 확인했다.
- Clipboard API 성공·거부를 각각 모의 실행했다. 성공 시 실제 넘긴 주소와 ‘복사됨’ 표시를 검증하고, 거부 시 정확한 주소를 선택하고 복사 안내를 표시함을 확인했다. OS 클립보드에 실제 기록됐다는 검증은 아니다.
- 대화형 시안에서 메일·외부 링크는 연결 대상만 표시한다. 실제 메일 앱 실행과 최종 서비스 브라우저별 클립보드 권한은 승인 후 구현 검증 범위다.
