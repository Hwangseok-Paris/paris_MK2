## 2026-11-28 - 홈 좌측 스크롤·우측 고정 승인

Status: Accepted (사용자의 시안 반영 및 PC 좌측 스크롤·숨긴 스크롤바·우측 고정, 모바일 보존 요청)

- 사용자는 홈에서 왼쪽만 스크롤하고 오른쪽은 고정하며, 왼쪽 스크롤바는 숨기는 방향을 제안했다. 현재 홈은 내용이 길면 좌우 전체가 늘어나 함께 스크롤된다.
- 승인 범위: 기존 650px 경계 이상에서는 홈을 화면 높이에 맞추고 오른쪽 메뉴를 같은 높이의 3단으로 유지한다. 왼쪽 고정 외곽 안에 별도 내용 스크롤 영역을 두어 색상 레이어는 움직이지 않게 한다. 스크롤바는 숨기되 휠·키보드·하단 연락처 접근을 보존한다.
- 기존 본문 flex 폭 계산과 내용·폰트·간격·모션을 유지한다. PC 홈에만 루트 scrollbar gutter를 해제해 오른쪽 빈 띠를 없앤다. 짧은 화면에서 메뉴 글자가 잘리지 않도록 세 메뉴의 PC 세로 padding을 없애되 중앙 정렬·클릭 영역은 유지한다.
- 650px 미만은 기존 문서 스크롤과 하단 고정 메뉴를 유지한다. 다른 페이지의 gutter도 유지한다. 프로젝트를 방문한 뒤 돌아오면 왼쪽 읽던 위치를 복원하는 것을 시안에 포함한다.
- HomeNavigation의 React 구조와 홈에 한정된 루트 Tailwind 규칙으로 구현했다. `useHomeScroll`은 모바일 포커스 제외·세션 내 읽던 위치 저장/복원·늦은 콘텐츠 높이 변경·사용자 입력 우선·이벤트 정리를 담당한다. 시안의 DOM 조정 코드는 서비스에 넣지 않는다.
- 검토용 `http://localhost:4310/__review`는 승인 반영 후 실제 localhost:3000 화면을 보여준다. 과거 비교/검증 자료는 `output/home-scroll-preview/`, 구현 검증 자료는 `output/home-scroll-implementation/`에 둔다.
